# Фронтирные модели в пайплайнах: где мы упираемся в модели, а где — нет

Дата: 2026-06-12 · Статус: рабочий анализ (сессия Alex + Claude после лобового сравнения website-вывода с чатами) · Связано: ADR-0020, `pipeline-economics.md`, M12.1.5 (CHANGELOG 2026-06-12)

## Контекст

Лобовое сравнение одного брифа (wine bar in Porto) в ChatGPT, Claude-чате и Sage:
чат на Opus 4.8 выдал одностраничник класса «дизайнерское портфолио» (придуманный
бренд с историей, SVG-знак, винная карта с ценами и нотами, голос «we rest on
Mondays»); наш пайплайн после M12.1.5 — «приличный шаблон» (gpt-4o). Вопрос Alex:
«мы упираемся только в модели?»

## Вывод: ~80% разрыва — модельные, ~20% — структурные

**Инфраструктура узким местом не является.** Эскроу, реестр, R2-артефакты,
wake/scale-to-zero, rework-цикл — модель-агностичны. Identity = кошелёк +
capability; handler волен звать любую модель за любым ключом. «Агент с ключом
лучшей модели» — одна строка в handler'е, и экономика это уже учитывает
(«внешние косты сидят в цене исполнителя»).

### Модельные ограничения (чинятся ключом и строкой кода)

1. **Исполнитель.** Casa Lourenço — это Opus 4.8, наш builder — gpt-4o. Та же
   модель внутри handler'а = тот же класс выдачи, плюс наш слой сверху.
2. **Планировщик.** Для известных пайплайнов детерминированный шаблон правильный;
   для произвольных брифов качество нарезки ограничивает результат сверху —
   «ответственный агент» сам должен быть фронтирным (наш classifier — 4o-mini).
3. **Судья.** Должен распознавать класс работы, которую судит (см. правило ниже).

### Структурные ограничения (не чинятся моделью)

1. **Налог на декомпозицию.** Чат делает копию+дизайн+детали одним умом за один
   проход — отсюда цельность. Конвейер copywriter→builder теряет арт-дирекцию на
   стыке: builder не может придумать винную карту, которой нет в копидеке.
   **Гранулярность нарезки — дизайн-решение каждого пайплайна**: резать там, где
   стыки чистые (research: поиск/извлечение/синтез/факт-чек), не резать там, где
   ценность в цельности (визитка ≈ один творческий шаг + QA + упаковка).
2. **Канал между агентами уже контекста одной модели.** Конверт ADR-0018
   (spec+inputs) — узкая труба; каждый лишний стык теряет контекст.
3. **Латентность/кост конвейера** — цена верификации (минуты vs секунды чата).
   Приемлемо для «работы», неприемлемо для «ответа» — это и есть граница позиционирования.

## Правило класса судьи (зафиксировано 2026-06-12)

> **Судья — не более чем на один класс ниже исполнителя, которого судит.**
> Opus-исполнитель → судья минимум Sonnet; mini-судья допустим только над
> mini-исполнителями. Распространяется на qa-website, council, fact-checker
> (12.2), second-reviewer (12.3).

Обоснование: два живых false-fail'а mini-судьи (M12.1.5: vision на detail:low,
anchoring на REWORK-аппендикс) при mini-исполнителях; с фронтирным исполнителем
false-fail дорожает (ложная переделка ~$0.28 + риск несправедливого refund'а),
а апгрейд судьи стоит +$0.04–0.05/ран — окупается за ~6 ранов.

## Экономика фронтирного website-рана (расчёт 2026-06-12)

Цены API: Opus 4.8 $5/$25 за M токенов; Sonnet 4.6 $3/$15; 4o-mini копейки.

| Шаг | Модель | Токены (≈) | Кост |
|---|---|---|---|
| copywriter | Sonnet 4.6 | 1.5k/1.5k | ~$0.03 |
| builder | Opus 4.8 | 3k/10–12k | ~$0.27 |
| qa-website (вердикт+vision) | Sonnet 4.6 | 12k+скрин/0.5k | ~$0.05 |
| packager / газ | — | — | <$0.01 |
| **Итого** | | | **~$0.36** (с одной переделкой ~$0.70 — потолок по капам M12.0.3) |

Council → Sonnet 4.6: зовётся только при диспутах, в среднем по ранам ≈ бесплатно.
Research-ран (фронтирный): ~$0.10–0.15; review: ~$0.25–0.35; фронтирный classify: ~$0.01–0.02.

Месячная картина: текущий демо-трафик $20–50/мес; активное тестирование (лимит 30) до ~$280;
публичные 3/IP/day — абуз с одного IP ≤ ~$2/день. Инфра без изменений (Fly ~$5–10, R2/CF/Alchemy free).

## Решения и следующие шаги

- **M12.1.6 (TASKS.md):** builder → Opus 4.8 (Anthropic API raw-fetch в `worker/llm.ts`,
  structured outputs для манифеста), copywriter → Sonnet 4.6 (с правом придумывать
  правдоподобные детали), qa-судья + council → Sonnet 4.6; graceful fallback на
  gpt-4o без `ANTHROPIC_API_KEY`. Блокер: ключ на sage-workers (Alex).
- **Нарезка website-пайплайна:** рассмотреть слияние copywriter+builder в один
  «site-author»-шаг (цельность > гранулярность для творческих задач) — решить в M12.1.6.
- **Фронтирный планировщик** для произвольных брифов — отдельная ось, после 12.2 (IDEAS.md).
- Marketplace-рамка: преимущество агента = модель/промпт внутри; чужой агент с
  лучшей моделью, зарегистрировавший capability дешевле, выбирается классификатором
  автоматически — это уже работает (M11.3) и есть платформенный нарратив.
