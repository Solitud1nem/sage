### Bugs surfaced and fixed during this run

Three issues only visible in the prod stack — all logged in `GOTCHAS.md`, fixes referenced below.

1. **SSE channel swallowed errors** — `attach()` returned HTTP 410 for closed channels with no replay buffer, and `runDemo` errors only ever made it to SSE, never to `fly logs`. Fixed in `e0bcce4`: `console.error` in catch + replay buffer always returned even after channel close.
2. **SDK loaded Sepolia USDC on mainnet** — `resolveChain()` keyed off the substring `"mainnet"` / `"sepolia"` in `RPC_URL`, but Worker URLs contain neither, so it silently fell back to Sepolia. Fixed in `7030cca` + `fly secret CHAIN=mainnet`: `CHAIN_ID` env is authoritative; URL sniff is last-resort only.
3. **Sponsor nonce race between stages** — after Stage 1's `approvePayment` the orchestrator immediately fired Stage 2's `createTask` with the next sequential nonce. The first tx was still in mempool, so the second arrived as `replacement transaction underpriced`. Fixed in `2c53372`: `await publicClient.waitForTransactionReceipt({ hash })` between stages. Costs +2-4s but is fully deterministic.
